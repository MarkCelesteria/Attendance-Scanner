How to get your Web App URL

  1. Open your Google Sheet.
  2. Click Extensions → Apps Script.
  3. Select everything in the editor (Ctrl+A), delete it, then paste the script.
  4. Click the Save icon (or press Ctrl+S).
  5. Click Deploy → New deployment. Next to "Select type", click the gear icon and choose Web app.
  6. Set Execute as: Me and Who has access: Anyone, then click Deploy.
  7. Click Authorize access and pick your Google account. If you see "Google hasn't verified this app", choose Advanced → Go to (your project) → Allow. This is normal for your own script.
  8. Copy the Web app URL (it ends in /exec) and paste it into the URL field.
Optional: protect it with an access key
  1. In the Apps Script editor, click the gear icon (Project Settings) in the left sidebar.
  2. Under Script properties, click Add script property.
  3. Set Property to ACCESS_KEY (capital letters) and Value to a password you choose, then click Save script properties.
  4. Type the same password into the Access key field in this app. Every device needs it.

No redeploy needed. To change the key, update it in both places. To turn it off, delete the property and clear the field. It keeps strangers out, but don't reuse a real password.

Changed the script later? Use Deploy → Manage deployments → Edit → New version. The URL stays the same.

Admin access

Enter the admin key set on the Apps Script (a separate key from the sync access key).
